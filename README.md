# AspaWeb Elevate

Build a premium, high-converting agency landing page for "AspaWeb".

Role & Tech Stack: Act as an elite UI/UX designer and Frontend Developer. Build this using React, Tailwind CSS, and Framer Motion for smooth, high-end animations. The code must be production-ready, fully responsive, and visually breathtaking.

Visual Theme & Art Direction:

Vibe: Modern AI startup meets premium design agency. Think Apple's product pages mixed with Web3 aesthetics.

Color Palette: Dark mode primary (Deep Space Black/Midnight Blue) with vibrant, glowing accent colors (Electric Cyan and Neon Purple gradients) to make the 3D elements pop.

UI Style: Use Glassmorphism (frosted glass panels with subtle white borders and background blur) for all cards and navigation.

3D Animations (CRITICAL): Integrate floating 3D animations using Framer Motion. Elements in the hero section and feature cards should have a continuous, gentle vertical float (levitation effect). Add a 3D tilt effect on hover for all buttons and cards.

Structure & Copywriting:

1. Navigation Bar (Sticky & Glassmorphic)

Logo: "AspaWeb" in a bold, modern, gradient font.

Links: Features, Pricing, Process.

CTA Button: "Chat on WhatsApp" (Style this as a glowing, pill-shaped button. Link to: [https://wa.me/](https://wa.me/)).

2. Hero Section (The 3D Centerpiece)

Layout: Split layout. Text on the left, floating 3D elements on the right.

Headline: "I Build High-Converting Websites for Local Businesses in 24-48 Hours." (Make "24-48 Hours" a glowing text gradient).

Subheadline: "Stop losing clients to competitors. I design, build, and launch fully managed, mobile-first websites so you can focus on running your business."

Hero CTA: Large primary button saying "Get Your Free Demo Demo" (Links to WhatsApp). Add a subtle pulse animation.

Right Side Visual: Create an abstract, floating 3D composition. Use layered, floating glass panels representing web pages, overlapping glowing 3D spheres, and 3D UI icons (like a rocket, a globe, and a phone). Make them float up and down continuously.

3. Introduction / Trust Section

Copy: "Hi, I'm Abdul Samad. I don't just sell websites; I build digital assets that get local tradesmen and businesses found on Google. No technical jargon, no server headaches. Just results."

4. Features Section (Grid Layout with 3D Hover Tilt)

Create a 3-column grid of glassmorphic cards. Each card must have a 3D floating icon at the top.

Card 1: 📱 Mobile-First Design (Fast, responsive, and looks perfect on any phone).

Card 2: ⚡ 24-48 Hour Turnaround (From saying 'yes' to a live URL in under two days).

Card 3: 💬 WhatsApp Integrated (Direct chat buttons so customers can reach you instantly).

Card 4: 🌍 Google Ready (Optimized for local search and Google Maps integration).

Card 5: 🛠️ Zero Maintenance (I handle the hosting, SSL, and updates).

Card 6: 🎨 3D & Modern UI (Premium designs that make you look like the top tier in your industry).

5. Pricing Section (Clear & Transparent)

Create one massive, highlighted pricing card in the center with a glowing border.

Title: The "Done-For-You" Package

Price: €400 Setup + €30/month (Hosting & Maintenance)

Bullets: 3-Page Custom Design, Free Domain Setup, Lightning Fast Hosting, SSL Certificate, Monthly Check-ups.

Button: "Start Your Project on WhatsApp"

6. Floating WhatsApp Widget (Global)

Place a persistent, floating 3D WhatsApp icon in the bottom right corner of the screen that remains visible as the user scrolls. Add a tooltip that says "Message me directly!"

Functional Requirements:

Ensure every button on the page triggers a direct href to a WhatsApp link.

Make sure the text is highly readable against the dark background (use crisp white and light gray text).

Ensure the floating animations do not cause horizontal scrolling issues on mobile devices.
